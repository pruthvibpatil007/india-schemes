# Indian Government Schemes Finder

A lightweight static web application that collects user demographic and socio-economic information and uses the Gemini API with structured JSON outputs to discover matching central and state government schemes in India.

## Files
- `index.html`: Responsive frontend user interface built with Tailwind CSS.
- `script.js`: Client-side logic for form collection and Gemini SDK integration.

## Hosting on GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html` and `script.js` to the root of the repository.
3. Go to **Settings > Pages**, set the source branch to `main` (or `root`), and click Save.
